# The use of indicators and metrics in global assessments and multilateral environmental agreements

This repository includes raw data (input) and code to extract and harmonise indicators and metrics (auto_search_indic.R,meas_indic_extract.R, tables_extract.R, harmonize_indic_func.R) from IPBES, IPCC, and GEO global assessments, as well as several MEAs.
It also includes ways to integrate indicators into one table (integration.R) and plot figures for a publication (plots_paper.R). Plus extra code with settings and useful functions (settings.R, useful_funcs_indic.R).
