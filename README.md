# The use of indicators and metrics in global assessments and multilateral environmental agreements

This repository is includes code to extract and harmonize indicators and metrics (auto_search_indic.R,meas_indic_extract.R, tables_extract.R). 
It also includes ways to integrate them into one table (integration.R) and plot figures for a publication (plots_paper.R). Plus extra code with settings and useful functions (settings.R, useful_functions_indic.R).

This repo accompanies the article: https://doi.org/10.5281/zenodo.17281329
