# The use of indicators in global assessments and multilateral environmental agreements

This repository is includes code to extract and harmonize indicators and metrics (auto_search_indic.R,meas_indic_extract.R, tables_extract.R). I also includes ways to integrate them into one table (integration.R) and plot figures for a publication (plots_paper.R). Plus extra code with settings and useful functions (settings.R, useful_functions_indic.R).
